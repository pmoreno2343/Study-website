STUDY WEBSITE — QUICK START

1. Open index.html in Chrome, Edge, Safari, or Firefox.
2. Notes, mistakes, plan checkboxes, daily question count, and scores are saved in your browser automatically.
3. Later you can publish it free with GitHub Pages, Netlify, or Cloudflare Pages.
4. Browser storage is device/browser-specific. If you later want accounts and cloud sync, the site can be upgraded to use a database.

Current features:
- Responsive dashboard
- Study subjects
- Notes storage
- Mistake/question log
- 30-day checklist
- Daily question and score tracker
- Search
- Quick-review values
